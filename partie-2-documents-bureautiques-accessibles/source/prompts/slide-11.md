# Étalon 11 - Traitement des images

Cas d'usage : productivity-visual.
Type d'actif : image finale d'une diapositive pédagogique IGPDE, paysage 16:9, composition visée 1672 × 941 pixels.

Images fournies : l'étalon 01 fixe le titre, les marges, les bleus et le dessin semi-plat ; la référence de comparaison fixe la lecture de gauche à droite. Les contenus propres à ces images ne doivent pas être recopiés.

Demande : représenter trois décisions distinctes devant trois images insérées dans un document bureautique. La fonction de l'image détermine son traitement accessible.

Scène : une communicante examine un document ouvert devant trois cas alignés. À gauche, une image informative simple reçoit un champ de remplacement court ; au centre, une image complexe reçoit une courte alternative et, à côté, un bloc de description détaillée figuré par des lignes sans mots ; à droite, un motif visuel redondant est désigné comme décoratif et n'est pas présenté comme porteur d'information. Trois cartes de même poids guident le regard de gauche à droite. Chaque carte porte exactement son libellé autorisé.

Masque commun : fond blanc dominant, très grand titre bleu nuit #000091 aligné à gauche en haut, cartes bleu très clair #E3EEFF à filets fins, icônes semi-plates cohérentes, flèches sobres si utiles, marges généreuses. Typographie Marianne ou Arial en repli. Le titre peut occuper deux lignes ; les trois libellés restent assez grands pour être lus en miniature. Pas de pied de page ni de numéro PPTX.

Texte visible autorisé, exactement :

- Station 2 - Choisir le bon traitement pour chaque image
- texte de remplacement
- description détaillée
- Marquer comme décoratif

Contraintes critiques : l'image informative et l'image complexe conservent une information à restituer ; seule l'image réellement redondante est marquée décorative. Ne pas mettre une longue description dans un petit champ alternatif. Aucune vraie phrase dans les fausses interfaces du document. Aucun autre mot, nombre, faux logo, emblème, pseudo-texte ou symbole ambigu. Ne pas ajouter de quatrième cas.

Test final : les trois choix sont perceptiblement différents et leur ordre est clair, sans devoir lire les procédures Word ou Writer de l'accordéon.
