# Étalon 03 - Fond ImageGen pour insertion des aperçus sources

Cas d'usage : infographic-diagram.
Type d'actif : image finale de fond pour une diapositive pédagogique IGPDE, paysage 16:9, composition visée 1672 × 941 pixels.

Image fournie : l'étalon 01 sert uniquement de référence pour la typographie, le bleu institutionnel, les marges et les filets. Ne pas en recopier la scène ni les mots.

Demande : créer le cadre du quiz A/B. Le titre et la question occupent le haut. Deux grands panneaux parfaitement symétriques occupent la moitié inférieure. Leur centre doit rester entièrement vide, uni et clair : deux images sources verticales seront insérées ensuite à cet endroit sans modification.

Composition précise : titre bleu nuit aligné à gauche dans les 100 premiers pixels ; question sous le titre ; à partir d'environ 200 pixels, deux panneaux aux contours bleu clair séparés par une gouttière d'environ 35 pixels. Le panneau gauche s'intitule « Document A », celui de droite « Document B ». Sous chaque label, réserver une zone unie blanche de même taille, d'environ 450 × 580 pixels, centrée dans le panneau. Cette zone ne contient absolument aucun document, graphique, trait, pictogramme, texte, ombre ou décor. Le reste de chaque panneau est bleu très clair et sobre.

Texte visible autorisé, exactement :

- Quiz - lequel de ces deux documents est accessible ?
- Ils sont visuellement identiques. Lequel préférez-vous pour NVDA ?
- Document A
- Document B

Style : fond blanc lumineux, grand titre bleu nuit #000091, bleu moyen #2B6DE8 seulement pour les bordures, typographie Marianne avec Arial en repli. Pas de résultat indiqué, pas de différence visuelle entre les panneaux, pas de pied de page ni de numéro PPTX. Aucun autre mot, chiffre, logo, pseudo-texte ou pictogramme.

Contrainte prioritaire : les deux zones d'insertion doivent être réellement vides et exactement symétriques. Ne pas inventer, simuler ni dessiner les aperçus des documents A et B.
