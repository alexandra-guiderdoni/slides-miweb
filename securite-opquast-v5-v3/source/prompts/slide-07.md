# Prompt ImageGen - slide 07

## Fiche PDS

- Rôle dans la colonne vertébrale : distinguer cinq règles voisines avant tout contrôle.
- Idée principale : couverture HTTPS, certificat, maintien en HTTPS, ressources HTTPS et visibilité de l'adresse sont cinq preuves différentes.
- Scène : cinq cartes alignées, chacune relie une question à une preuve distincte.
- Objet-système : navigateur central décliné en cinq contrôles visuels.
- Transformation visible : une idée vague de HTTPS se décompose en cinq questions contrôlables.
- Ce que l'image seule doit faire comprendre : les règles 197, 198, 199, 200 et 216 ne sont pas interchangeables.
- Contraintes critiques : cinq cartes et cinq questions exactes, aucun regroupement ni inversion.

## Prompt complet

Cas d'usage : infographic-diagram.
Type d'actif : image finale de slide de formation, paysage 16:9, exactement 1672 x 941 pixels.

Utiliser les références comme masque visuel strict : fond blanc, bleu marine, cartes bleu très clair et gris froid, vert pour les preuves, corail rare pour un défaut, icônes filaires, typographie Marianne avec Arial comme fallback. Aucun dégradé, aucune 3D, aucune photographie, aucun faux logo.

Composition : sous le bandeau supérieur commun, disposer cinq cartes verticales de même taille sur une ligne ou en quinconce très régulier. Chaque carte contient un numéro, une question courte exacte et un pictogramme distinct : pages HTTPS, certificat, maintien du canal, ressources chargées, barre d'adresse visible. Relier les cartes par une ligne fine qui exprime cinq preuves complémentaires, sans les fusionner. Garder chaque phrase lisible en résolution de projection.

Texte visible exact, et aucun autre texte :

- `QUALITÉ NUMÉRIQUE - OPQUAST V5`
- `197 - Toutes les pages passent-elles par HTTPS ?`
- `198 - Le certificat est-il signé et valide ?`
- `199 - Le navigateur doit-il rester en HTTPS ?`
- `200 - Toutes les ressources passent-elles aussi par HTTPS ?`
- `216 - L'utilisateur voit-il toujours l'adresse ?`
- `Opquast - présentation Miweb`
- `07 / 30`

Masque commun : bandeau supérieur gauche, cinq cartes dans la zone centrale, footer bas gauche, pagination bas droite. Aucun logo.

Contraintes critiques : aucune question ne doit manquer ; conserver chaque numéro, le tiret simple et sa question comme une seule étiquette lisible ; ne pas répéter `HTTPS` dans les illustrations, qui restent purement iconographiques ; ne pas écrire `HTTP` à la place de `HTTPS` ; ne pas ajouter de réponse, de code, d'URL, de logo ou de texte parasite.
