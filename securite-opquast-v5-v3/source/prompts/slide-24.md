# Prompt ImageGen - slide 24

## Fiche PDS

- Rôle dans la colonne vertébrale : atelier de synthèse du chapitre C.
- Idée principale : une preuve se cherche à la fois dans les entêtes réseau et dans le code source.
- Scène : une développeuse examine un écran partagé entre l'onglet Réseau et un extrait HTML.
- Objet-système : poste d'inspection en deux panneaux complémentaires.
- Transformation visible : les indices observés convergent vers un verdict prudent.
- Ce que l'image seule doit faire comprendre : présence, validité et portée doivent être distinguées.
- Préparation de la suite : ouvre le contrôle de ce que le serveur révèle.
- Contraintes critiques : tous les termes techniques exacts, aucune valeur inventée, verdict avec point d'interrogation.

## Prompt complet

Cas d'usage : productivity-visual.
Type d'actif : image finale de slide de formation, paysage 16:9, 1672 x 941 pixels.

Créer une slide institutionnelle française reprenant exactement le masque clair des étalons validés Sécurité Opquast V5 V3 : fond blanc dominant, petit bandeau supérieur, grand titre bleu marine aligné à gauche, repère de chapitre discret, panneaux pastel très clairs, illustrations plates, traits fins, beaucoup d'espace blanc, callout bleu clair centré en bas, footer bas gauche et pagination bas droite. Typographie Marianne obligatoire, Arial seulement comme fallback. Aucun dégradé, aucune 3D, aucune photographie, aucune ombre lourde, aucun logo.

Composition : une développeuse au centre inspecte deux grands panneaux de même importance. À gauche, panneau `ENTÊTES` sous forme d'onglet Réseau avec quatre lignes techniques courtes. À droite, panneau `CODE SOURCE` avec un seul extrait HTML court. Des loupes ou coches sobres relient les indices à un espace de verdict inférieur. Ne pas simuler une capture réaliste illisible : privilégier de grands libellés exacts et une hiérarchie nette.

Texte visible exact, et aucun autre texte :

- `QUALITÉ NUMÉRIQUE - OPQUAST V5`
- `C - INSTRUCTIONS AU NAVIGATEUR`
- `Atelier : lire les entêtes et le code source`
- `ENTÊTES`
- `Content-Type`
- `X-Content-Type-Options: nosniff`
- `Content-Security-Policy`
- `X-Frame-Options ou frame-ancestors`
- `CODE SOURCE`
- `integrity="sha384-..."`
- `VERDICT - Présent, valide ou indéterminé ?`
- `Opquast - présentation Miweb`
- `24 / 30`

Contraintes critiques : séparer nettement entêtes et code source ; conserver exactement la casse, les deux-points, les traits d'union, les guillemets et `sha384` ; ne pas ajouter de règle, d'URL, de fournisseur ou de code supplémentaire ; aucun texte parasite.
