# Prompt ImageGen - slide 17

## Fiche PDS

- Rôle : ouvrir le chapitre C par le risque d’instructions inadaptées données au navigateur.
- Scène : un navigateur central reçoit six consignes distinctes.
- Transformation : les ressources incontrôlées deviennent six points de contrôle explicites.
- Continuité : quitte le compte pour les réponses HTTP et prépare le couple MIME.
- Contrainte critique : six consignes distinctes, aucune équivalence implicite.

## Prompt complet

Cas d’usage : infographic-diagram.
Type d’actif : image finale de slide de formation, paysage 16:9, 1672 x 941 pixels.

Reprendre exactement le masque clair des étalons : fond blanc, en-tête commun, repère de chapitre bleu clair, grand titre bleu marine, illustration plate, panneaux pastel, footer bas gauche et pagination bas droite. Bleu pour la structure, corail pour un contenu refusé, vert pour une consigne acceptée. Marianne obligatoire, Arial en fallback. Aucun dégradé, aucune 3D, aucune photographie, aucun faux logo.

Composition : navigateur central relié à six petites consignes visuelles autour de lui : type déclaré, interdiction de deviner, protection XSS, encadrement, origines autorisées et intégrité. Les six repères sont distincts, équilibrés et sans texte technique supplémentaire. Faire comprendre que le navigateur reçoit des règles avant d’interpréter, charger ou exécuter.

Texte visible exact, et aucun autre texte :

- `QUALITÉ NUMÉRIQUE - OPQUAST V5`
- `C - INSTRUCTIONS AU NAVIGATEUR`
- `Chapitre C : dire au navigateur ce qu'il peut accepter`
- `Déclarer la nature, les sources, les cadres et l'intégrité.`
- `206 · 207 · 210 · 211 · 212 · 214`
- `Opquast - présentation Miweb`
- `17 / 30`

Contraintes critiques : six consignes visibles et distinctes ; ne pas ajouter de septième règle, de code long, d’URL, de fournisseur, de logo ou de texte parasite.
