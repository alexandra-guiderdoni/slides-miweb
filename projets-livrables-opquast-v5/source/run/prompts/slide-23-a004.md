# Reprise image_gen - slide 23 - tentative a004

## Fiche PDS

- Rôle : bilan visuel des trois études de cas avant l’inventaire.
- Idée principale : cinq règles imposent cinq objets de contrôle différents.
- Scène : cinq postes de contrôle courts convergent vers une validation commune.
- Objet-système : cinq cartes numérotées avec une icône et un libellé bref.
- Transformation visible : la densité textuelle disparaît au profit d’une lecture immédiate.
- Masque commun : en-tête, titre, badge, footer et pagination de la série.
- Image seule : comprendre en trois secondes que chaque règle se contrôle autrement.
- Continuité : conclure les études de cas et préparer l’atlas des livrables.
- Contraintes critiques : cinq associations exactes, aucune formulation longue, aucun texte parasite.
- Risque : recréer une fiche documentaire dense ou ajouter un second message.

## Prompt

Cas d’usage : productivity-visual.
Type d’actif : image finale de slide institutionnelle française, paysage 16:9.

Reprendre la slide de référence dans le même style, mais simplifier radicalement
son centre. Conserver le fond blanc, le bleu institutionnel, les bordures fines,
les panneaux très clairs, les icônes filaires, la typographie Marianne avec
fallback Arial et de grands espaces. Aucun dégradé, aucune 3D, aucun blob,
aucune photographie, aucun faux logo.

Conserver exactement l’en-tête :
- haut gauche : `QUALITÉ WEB`, puis `EXPÉRIENCES DURABLES` ;
- haut droit : `Opquast`, puis `DES SITES MEILLEURS POUR TOUS` ;
- aucun symbole devant `Opquast`.

Titre aligné à gauche, moins haut que dans la tentative précédente :
`Cinq règles, cinq preuves différentes`

Créer une composition forte et aérée : cinq cartes de même importance sur une
seule ligne ou sur un arc très léger. Chaque carte contient uniquement un grand
numéro, une icône filaire distincte et un libellé court :

- `234` - icône de plan de document - `Plan de titres HTML`
- `77` - icône d’œil et de champ - `Proximité visuelle`
- `69` - icône de liaison ou de code - `Liaison champ-étiquette`
- `85` - icône d’envoi validé - `Résultat de la soumission`
- `222` - icône de réponse serveur 404 - `Statut HTTP`

Les cinq cartes convergent visuellement vers une validation verte discrète,
sans ajouter de nouveau libellé. Le regard doit comprendre immédiatement que
les preuves sont différentes mais qu’elles participent au même bilan.

Callout vert centré, exactement :
`Une exigence circule. La preuve vient du rendu.`

Conserver exactement le bas de page :
- badge gauche : `ESSENTIEL 60` ;
- footer : `RÈGLES OPQUAST · PROJETS ET LIVRABLES` ;
- pagination droite : `23 / 45`.

Liste blanche exhaustive : `QUALITÉ WEB` ; `EXPÉRIENCES DURABLES` ; `Opquast` ;
`DES SITES MEILLEURS POUR TOUS` ; `Cinq règles, cinq preuves différentes` ;
`234` ; `Plan de titres HTML` ; `77` ; `Proximité visuelle` ; `69` ;

Aucun autre texte. Ne pas afficher les intitulés officiels complets sur l’image.
Ne pas afficher la boucle constat-décision-correction-recontrôle. Ne pas poser de
question. Ne pas tronquer, inverser ou mélanger les cinq associations.
