# Sources — accessibilité web en octobre

Statut : sources vérifiées par consultation web le 4 octobre 2026.
Ces sources remplacent la provenance personnelle initialement mentionnée ; cette provenance ne doit pas apparaître dans la série.

## S1 — W3C, History

- URL : https://www.w3.org/about/history/
- Usage : établir qu’en octobre 1990, Tim Berners-Lee a écrit le premier client Web, un navigateur et éditeur appelé `WorldWideWeb`.
- Extrait utilisé, paraphrasé dans la série : premier serveur Web `httpd` et premier programme client `WorldWideWeb`, navigateur et éditeur, en octobre 1990.

## S2 — W3C, World Wide Web Consortium founded

- URL : https://www.w3.org/news/1994/world-wide-web-consortium-w3c-founded/
- Usage : établir la date de fondation du W3C.
- Extrait utilisé, paraphrasé dans la série : W3C fondé le 1er octobre 1994.

## S3 — W3C, Accessibility — Our mission

- URL : https://www.w3.org/mission/accessibility/
- Usage : citation de Tim Berners-Lee et cadrage de l’accessibilité du Web.
- Citation à conserver, traduction française proposée pour affichage : « La puissance du Web réside dans son universalité. Son accès par toutes et tous, indépendamment du handicap, en est un aspect essentiel. » — Tim Berners-Lee.
- Note : la citation originale anglaise visible sur la page W3C est : “The power of the Web is in its universality. Access by everyone regardless of disability is an essential aspect.”
