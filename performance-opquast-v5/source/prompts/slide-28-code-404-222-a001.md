# Prompt image_gen - slide 28, code HTTP 404

Générer une seule slide raster complète en français, texte compris, sur un canevas paysage 16:9 de 1672 x 941 px.

## Intention

Expliquer qu’une ressource absente doit produire un véritable code de statut HTTP 404. Le signal technique doit être compris par les navigateurs et les robots, indépendamment de l’apparence de la page d’erreur.

## Direction visuelle

Infographie éditoriale institutionnelle française, sobre, lumineuse et immédiatement lisible. Fond blanc dominant, espace blanc généreux, typographie sans-serif proche de Marianne avec Arial comme fallback. Bleu marine pour la structure, bleu clair pour la requête et vert discret pour le signal correct. Cartes arrondies, traits nets, ombres très faibles, icônes filaires simples. Aucun élément ne doit être distingué par la couleur seule.

## Composition

- Conserver le masque visuel de la série : en-tête institutionnel, titre centré, grand contenu central, pied de page et pagination.
- Titre : `Une ressource absente doit répondre 404`.
- Badge central `RÈGLE 222`.
- Représenter une requête vers une ressource manquante, puis une réponse serveur explicite.
- Libellé de situation : `RESSOURCE INTROUVABLE`.
- Le code `HTTP 404` doit être l’élément le plus saillant.
- Conclusion visuelle : `Un signal fiable pour les navigateurs et les robots`.
- Ne pas représenter de code 200, afin d’éviter une comparaison ambiguë.

## Mise en page verrouillée

- En haut à gauche : `QUALITÉ WEB`, puis `EXPÉRIENCES DURABLES`.
- En haut à droite : `Opquast`, puis `DES SITES MEILLEURS POUR TOUS`.
- En bas : footer `RÈGLES OPQUAST · PERFORMANCE` et pagination `28 / 35`.
- Marges de sécurité : 72 px minimum.
- Une idée principale, lecture en trois secondes, aucun petit texte.

## Contraintes critiques et critères de rejet

- Le code `HTTP 404` doit être exact, unique et immédiatement lisible.
- La ressource doit être clairement absente ou introuvable.
- Le visuel doit distinguer la situation, le statut serveur et les destinataires du signal.
- Rejeter toute faute, code 200, autre statut HTTP, texte parasite, mauvais numéro ou pagination incorrecte.
- Pas de faux logo, photo corporate, personnage, 3D décorative, gros dégradé, texture, pseudo-texte, fil d’Ariane, barre de progression, watermark ni marque inventée.
