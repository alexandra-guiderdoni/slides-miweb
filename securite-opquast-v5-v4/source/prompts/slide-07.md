## Fiche PDS

- Rôle : distinguer cinq règles voisines avant tout contrôle.
- Idée principale : les règles 197, 198, 199, 200 et 216 apportent cinq preuves non interchangeables.
- Objet-système : cinq cartes techniques comparables reliées par une progression.
- Transformation visible : une idée vague de HTTPS devient cinq questions contrôlables.
- Contraintes critiques : cinq cartes, cinq questions exactes, aucune répétition dans les pictogrammes.

## Prompt complet

Créer une image finale de slide de formation institutionnelle française au format paysage 16:9, exactement 1672 x 941 pixels.

Suivre très fidèlement la direction artistique des cinq références fournies : fond ivoire presque blanc, bleu marine, cartes pastel très claires, vert discret pour les preuves, corail rare, pictogrammes vectoriels filaires, typographie française sans sérif proche de Marianne. Aucun dégradé, aucune photographie, aucune 3D, aucune ombre lourde, aucun faux logo.

Masque stable V4 : micro-entête en haut à gauche, cinq cartes dans la zone centrale, footer bas gauche, pagination bas droite. Aucun titre ou badge supplémentaire.

Composition : disposer cinq cartes verticales de même taille sur une ligne, reliées par de fines flèches bleues. Chaque carte contient un numéro, une question exacte et un pictogramme sans texte : pages, certificat, navigateur maintenu, ressources chargées et barre d'adresse visible. Les libellés restent grands et parfaitement lisibles.

Texte visible exact, et absolument aucun autre texte :

- `QUALITÉ NUMÉRIQUE - OPQUAST V5`
- `197 - Toutes les pages passent-elles par HTTPS ?`
- `198 - Le certificat est-il signé et valide ?`
- `199 - Le navigateur doit-il rester en HTTPS ?`
- `200 - Toutes les ressources passent-elles aussi par HTTPS ?`
- `216 - L'utilisateur voit-il toujours l'adresse ?`
- `Opquast - présentation Miweb`
- `07 / 30`

Priorités de lecture : 1. les cinq numéros ; 2. les cinq questions ; 3. leurs pictogrammes distincts.

Critères de rejet : question manquante, regroupement, inversion, répétition de HTTPS dans les illustrations, HTTP à la place de HTTPS, tiret différent, texte parasite, faux logo, mauvaise pagination.
