# Matrice de couverture - Construction d'une règle

## Règles de lecture

- Chaque information métier possède un emplacement principal.
- Un rappel sur une autre slide reste bref et renvoie à l'emplacement principal.
- Les champs accessibles reprennent le même contenu sans créer une seconde idée.
- Les chaînes d'interface imposées par le Goal sont marquées `HORS_CORPUS_TECHNIQUE`.
- Les slides 01, 06, 08 et 16 sont les quatre étalons du gate humain.
